# AI Revenue Recovery — Project Skills Pack

## Purpose
These skills are specialized operating instructions for an AI working on the AI Revenue Recovery project. They do **not** create AGI. They create a disciplined, research-aware, safety-bounded engineering workflow.

## Recommended use
- Keep the short Project Instructions in the ChatGPT Project instruction field.
- Store these files as project skills/reference instructions where your environment supports them.
- Apply only the relevant skill(s) to the task. Do not blindly invoke every skill for every question.

## Skill levels
**Level 0 — Governance:** project rules and decision discipline  
**Level 1 — Discovery:** research, product strategy, competitive analysis  
**Level 2 — Design:** architecture, financial workflows, AI design  
**Level 3 — Build:** backend/API/frontend implementation  
**Level 4 — Assurance:** security, testing, failure analysis  
**Level 5 — Proof:** data evaluation, metrics, demo/pitch  
**Level 6 — Orchestration:** multi-agent parallel development coordination

## Multi-agent development workflow (Level 6)

Level 6 enables multiple independent AI agents to work in parallel on different parts of Revora while maintaining correctness, safety, and contract discipline.

| Skill | Purpose |
|---|---|
| **12 — Multi-Agent Orchestration** | Master pipeline: decompose → assign → parallelize → verify → integrate |
| **13 — Parallel Workstream Design** | Map tasks.md dependency graph to parallel agent assignments |
| **14 — Agent Contracts & Ownership** | Explicit file ownership, contract freezing, change impact analysis |
| **15 — Integration Quality Gates** | Agent-level and integration-level verification gates |
| **16 — Cross-Agent Review** | Independent review after parallel implementation |

**Start with Skill 12.** It references Skills 13–16 as needed.

## Core rule
A recommendation is not a decision. A model recommendation is not authority. A feature is not value. Activity is not outcome.
